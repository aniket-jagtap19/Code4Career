# Code4Career

**Code4Career** is an AI-powered intra-college platform that unifies coding contests, placement preparation, and personalized learning into a single structured ecosystem. It bridges the gap between random practice and placement readiness through AI-driven insights and guided improvement.

---

## Problem Statement

Students prepare for coding, aptitude, and development using multiple disconnected platforms.
This leads to:

* Lack of structured learning
* No centralized progress tracking
* Limited feedback after contests

---

## Solution

Code4Career provides a **single integrated platform** that combines:

* Contest practice (DSA, CP, Aptitude, Development)
* AI-powered performance analysis
* Personalized upsolving through an AI Tutor

---

## Tech Stack

* **Frontend:** React, TypeScript
* **Backend & Database:** Firebase (Authentication, Firestore)
* **Hosting:** Firebase Hosting
* **AI Integration:** Google Gemini API

---

## Key Features

### AI Tutor

* Post-contest analysis using AI
* Identifies strengths, weaknesses, and mistake patterns
* Provides guided explanations and upsolving support

---

### Contest System

* College-based contests (DSA, CP, Dev, Aptitude)
* Structured evaluation environment

---

### 📊 Performance Analytics

* AI-generated insights for each user
* Tracks growth and improvement over time

---

### Leaderboards

* Division-wise rankings
* Encourages healthy competition

---

### Admin Dashboard

* Student performance tracking
* Analytics and reports for institutions

---

## Unique Innovations

* Centralized platform replacing multiple tools
* AI-driven feedback instead of manual analysis
* Personalized learning after contests
* Designed specifically for intra-college ecosystems

---

## How It Works

1. User logs in via Google Authentication
2. Gets assigned a division automatically
3. Participates in contests
4. Receives AI-generated performance analysis
5. Uses AI Tutor for upsolving and improvement
